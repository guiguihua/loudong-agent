## 负向控制

- 已经参数化的安全基线会在修复搜索前被阻断。
- 缺少业务 Oracle 时只返回 `candidate_only`，不会被内核接受为自动修复。
- 模型连续生成同一错误 SQL 拼接策略时，两轮产生相同语义指纹。
- 错误策略进入 `CounterexampleMemory` 后，最后一轮确定性参数化回退成功。
- 所有最终 diff 都在第二个全新临时工作区执行 `git apply --check` 和 `git apply`。
- 安全和业务 Oracle 使用相同双向命令时只执行一次，但分别保存两类证据。
